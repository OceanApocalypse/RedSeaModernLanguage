A read-only buffer backed by a span of characters. All operations opt for performance primarily via the internal use of ReadOnlySpan<T> over string allocations and also via caching.

Remarks

Tip

The main advantage of this type over ReadOnlyStringBuffer is that you don't need to allocate a class and, on initialization, you don't need to allocate a string.
