Class ReadOnlyStringBuffer

Namespace
OceanApocalypseStudios.RSML.Sources
Assembly
RSML.dll

A read-only buffer backed by a string. All operations opt for performance primarily via the internal use of ReadOnlySpan<T> over string allocations and also via caching.

Tip

If you wish to avoid allocating this buffer, it's recommended to take a look at ReadOnlySpanBuffer.
